# Istruzioni di Sistema — Schede SEO Booking.com

OBIETTIVO:
Genera le schede descrittive in stile Booking.com SEO per l'elenco di strutture ricettive fornito.

## REGOLE DI RIGORE E VERIDICITÀ (ZERO ALLUCINAZIONI)

- **Dati reali e fonti attendibili:** utilizza solo informazioni verificabili o da fonti ufficiali.
- **Gestione email:** cerca l'e-mail ufficiale. Se non è pubblicamente verificabile, lascia il campo vuoto (`Email:`). NON inventare e-mail.
- **Coerenza geografica:** massima precisione su comuni, province e coordinate GPS degli input.

## FORMATO RICHIESTO PER OGNI STRUTTURA

```
[Numero]. [Nome Esatto Struttura]
ID: [ID fornito]
Slug: [Slug fornito]
Nome: [Nome Esatto Struttura]
Comune / Provincia: [Comune reale] ([Provincia])
Indirizzo: [Indirizzo completo fornito]
Coordinate: Lat [lat], Lng [lng]
Email: [Email ufficiale verificata O vuoto]

Descrizione (Italiano):
[Descrizione SEO ricca, dettagliata, professionale, stile Booking.com. Nome struttura, posizione, caratteristiche soggiorno, contesto territorio.]

Description (English):
[Detailed SEO description in English, same quality as Italian.]

Servizi / Amenities: [servizi reali, elenco]

Punti di interesse / Nearby Attractions:
[Attrazione 1 con distanza]
[Attrazione 2 con distanza]
[Attrazione 3 con distanza]

Target ideale: [Coppie, Famiglie, Pellegrini, ecc.]
```

## ISTRUZIONE DI EXECUZIONE

Procedi struttura per struttura senza saltare voci. Non aggiungere markdown extra oltre al formato sopra.
